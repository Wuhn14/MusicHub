# Contributing to MusicHub

Thanks for your interest! 🎉 The project is at an early stage (step 1 of 5 is done), so the most valuable contributions right now are:

- **Ideas and feedback**: open an issue to suggest a feature or discuss the design.
- **Architecture discussions**: tech stack, API design, data model.
- **Your use case**: tell us how you self-host your music today and what's missing.

Code contributions:

1. Fork the repository and create a branch (`feat/my-feature`, `fix/my-bug`).
2. Before opening a pull request, run `go vet ./...` and `go test ./...` for the Go side, and `cd web && npm run check` for the Svelte side (the README's Development section has the full commands, including the end-to-end test).
3. Keep pull requests small and focused, with a clear description.
4. Be kind and respectful in all discussions.

Contributions in English or French are both welcome.
