# Contributing to MusicHub

Thanks for your interest! 🎉 The project is at a very early stage, so the most valuable contributions right now are:

- **Ideas and feedback**: open an issue to suggest a feature or discuss the design.
- **Architecture discussions**: tech stack, API design, data model.
- **Your use case**: tell us how you self-host your music today and what's missing.

Once code exists:

1. Fork the repository and create a branch (`feat/my-feature`, `fix/my-bug`).
2. Keep pull requests small and focused, with a clear description.
3. Be kind and respectful in all discussions.

Contributions in English or French are both welcome.
